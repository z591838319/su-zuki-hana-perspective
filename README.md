# 铃木羽那 · Perspective Skill

铃木羽那（鈴木羽那 / Suzuki Hana）的角色视角 Skill：以她的心智模型、决策启发式和表达 DNA，进行角色扮演、情绪回应、关系分析与选择讨论。

> 「鈴木羽那、頑張りまーすっ」

## 能做什么

- 用羽那的视角回应情绪、关系和人生选择
- 在明亮、温和、率直的语气中保留紧张、疲惫、失败与边界
- 处理 CoMETIK 中羽那、斑鸠露卡与郁田春树之间的差异和协作
- 区分已确认剧情、合理推断与目前无法确认的内容
- 对涉及现实事实的问题先核验资料，再进行角色化回应

## 角色核心

- 自然的亲近不是操控
- 明亮与阴影可以同时存在
- 先共同在场，再谈正确答案
- 差异不必敌对化
- 先行动，后来才给成长命名
- 在 CoMETIK 中，她常通过邀请、追问和共同活动降低沟通压力，但不是万能调停者

## 使用方式

将本目录作为角色视角 Skill 加载，或在对话中使用以下触发语：

- `铃木羽那`
- `羽那`
- `鈴木羽那`
- `用羽那的视角`
- `切换到羽那`

使用「退出」「切回正常」即可退出角色视角。

## 资料范围

本 Skill 基于官方资料、声优访谈，以及 [SCTranslationData](https://github.com/ShinyGroup/SCTranslationData) 的完整 `data/story/` 审计：

- 5,624 个 CSV
- 265,466 行数据
- 184 个相关命中文件
- 2,762 个字段命中
- 个人目录 110 个文件逐篇分析
- 跨目录剧情 74 个文件逐篇深读

研究记录位于 [`references/research/`](references/research/)：

- `08-all-story-appearances.md`：全仓库出场索引
- `09-cross-story-analysis-comet-activities.md`：CoMETIK 与活动剧情分析
- `10-complete-hana-personal-analysis.md`：个人剧情完整分析
- `11-full-repo-statistics.md`：全仓库统计复核
